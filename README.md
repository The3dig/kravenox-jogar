# Kravenox: Cratera do Cisma

**Jogar:** https://the3dig.github.io/kravenox-jogar

No iPhone, abra no Safari e toque em **Compartilhar → Adicionar à Tela de
Início** para jogar em tela cheia, como um app.

Arraste o dedo para andar; os ataques são automáticos. Sobreviva 15 minutos.

---

Este repositório guarda só o jogo montado (exportação Web do Godot 4.5).
Não edite estes arquivos à mão: eles são gerados pelo projeto do jogo.
